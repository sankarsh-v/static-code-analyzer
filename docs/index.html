1. Compiler Phase Mapping

                    

                        

                            Lexical Analysis
                            lexer.c/.h: converts C source bytes to Token stream, skips comments & preprocessor
                        

                        
→

                        

                            Syntax Analysis
                            parser.c/.h: recursive-descent + precedence climbing AST construction
                        

                        
→

                        

                            Semantic Analysis
                            symtab.c/.h: nested scope stack, identifier resolution & type checking
                        

                        
→

                        

                            Static Quality Checks
                            checks.c/.h: W001-W014 smell & safety rule passes over AST
                        

                        
→

                        

                            Diagnostics Report
                            Console & self-contained HTML visual report
                        

                    

                    
Why is there no Code Generation phase? Because this is a static code quality analyzer. Its purpose is verification, safety auditing, and smell detection. Generating target machine code or executing untrusted student code would introduce severe security vulnerabilities.

                


                

                    
2. Top University Viva Questions

                    

                        

                            
Q: What is the difference between a Parse Tree and an Abstract Syntax Tree (AST)?

                            
A: A Parse Tree (Concrete Syntax Tree) contains every grammar symbol including punctuation, semicolons, and parentheses. An AST retains only the semantic hierarchy and essential nodes (e.g. operators, operands, statements), omitting syntactic noise.

                        

                        

                            
Q: How does your parser resolve operator precedence?

                            
A: We use precedence climbing in parse_expr_precedence. Each binary operator is assigned an integer precedence level and associativity, allowing compact, high-performance recursive expression parsing without 15 separate grammar functions.

                        

                        

                            
Q: How are scopes represented in the symbol table?

                            
A: As a linked stack of scope structures (Scope), where each scope contains a dynamic list of declared Symbols and a pointer to its parent enclosing scope. Variable lookup walks innermost to outermost scope.

                        

                        

                            
Q: How does Rule W013 detect division by zero?

                            
A: It inspects binary expressions with operator / or %. If the right-hand child node is an IntLiteral with integer value 0, it emits a fatal safety error without ever executing the division.
